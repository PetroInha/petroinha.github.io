# CURE Lab — petroinha.github.io

Website of the **Center for Unconventional Resources and Energy (CURE)** at Inha
University: AI-powered subsurface engineering — CO₂ geological storage, underground
hydrogen storage, digital rock physics and reservoir modeling.

Live site: <https://petroinha.github.io>

## How the site is built

Jekyll (minima theme) on the default GitHub Pages builder. Every push to `main`
rebuilds the site; there is no Actions workflow and nothing to run locally.

Plugins (all on the GitHub Pages whitelist): `jekyll-feed` (`/feed.xml`),
`jekyll-seo-tag` (meta / Open Graph tags), `jekyll-sitemap` (`/sitemap.xml`).

## Layout

| Path | What it is |
|---|---|
| `index.markdown` | Homepage — hero slider, event card, research topics, Recent Highlights |
| `i_1_members.markdown` | Team |
| `i_3_Lectures.markdown` | Courses |
| `i_4_Publications.markdown` | Publications by year (keep in sync with Google Scholar) |
| `i_5_Projects.markdown` | Funded projects |
| `i_7_energy_stats.markdown` | Energy market dashboard page (embeds `_images/energy_stats*.html`) |
| `_posts/` | News posts, one file per event |
| `_images/` | Photos and the generated dashboard HTML |
| `_script/` | Dashboard data pipeline — **git-ignored**, lives only on the lab machine |
| `_confidential/` | Planning documents — **git-ignored**, never published |

Pages use inline `<style>` blocks; there is no shared stylesheet. The brand blue is
`#005BAC`.

## Adding a news post

1. Create `_posts/YYYY-M-D-Short-Title.markdown` with front matter:

   ```yaml
   ---
   layout: post
   title: "Short Title"
   date: YYYY-MM-DD 18:00:00 +0900
   categories: jekyll update
   ---
   ```

2. Put the photo in `_images/` and reference it by its raw GitHub URL —
   `_images/` is not served as a normal site folder:

   ```html
   <img src="https://raw.githubusercontent.com/PetroInha/petroinha.github.io/main/_images/photo.jpg">
   ```

   Keep photos web-sized (≤ 2400 px on the long edge, ~0.5–1 MB). Phone originals
   are 3–5 MB each and slow every page that shows them.

3. The post's URL will be `/jekyll/update/YYYY/MM/DD/Short-Title.html`. Link to it
   from the homepage's Recent Highlights if it deserves a card.

**Posts dated in the future are not published** until that date passes. Announce
an upcoming event with today's date, then update the post afterwards.

## Energy dashboard

`_images/energy_stats_hourly.html` is regenerated by a scheduler on the lab
machine, which commits and pushes it on its own. Expect those commits in the
history; do not hand-edit the file.
